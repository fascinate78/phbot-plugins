# FPenManager Changelog

## v1.0.0

### Added
- Added response-driven Feather Pen of Fortune automation with independent minimum total values for each selected stat.
- Added summation of repeated stat lines, multi-item queuing, inventory-slot validation, and automatic progression between completed items.
- Added verified decoding of the changed stat key, old and new values, and the complete current stat record section from `0xB151` responses.
- Added a one-roll test and a two-page GUI with live result and automation status indicators.
